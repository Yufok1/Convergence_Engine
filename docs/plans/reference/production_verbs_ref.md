## 1. CREATING VERBS (18 verbs)

**Definition**: Intentional production of artifacts, structures, or objects through skill and materials.

### Production Complexity Hierarchy

**Artistic/Skilled Creation**
- craft, forge, fashion, design, devise, invent

**Large-Scale Manufacturing**
- manufacture, produce, fabricate, assemble

**Foundational Creation**
- create, make, generate, build, construct

**Compositional Creation**
- compose, concoct, formulate, design

### Key Antonym Pairs
- create ↔ destroy (existence vs. nonexistence)
- build ↔ demolish (construction vs. destruction)
- make ↔ break (production vs. damage)
- assemble ↔ disassemble (construction vs. dismantling)

### Causal Patterns
- Creative intent + materials → create → object existence → artifact
- Design intent + materials + labor → build → structure completion → usable space
- Artistic skill + materials → craft → handmade product → unique artifact
- Components + instruction → assemble → complete object → functional unit

## 2. GROWING VERBS (13 verbs)

**Definition**: Biological production through natural processes of development and maturation.

### Plant Life Cycle Progression

**Initiation**
- germinate, sprout, shoot, emerge

**Development**
- grow, develop, mature, ripen

**Reproductive**
- bud, bloom, flower, reproduce

**Renewal**
- regenerate, breed, spawn

### Growth Stage Taxonomy
- **Germination**: germinate, sprout (initial growth)
- **Vegetative**: grow, develop (leaf/stem growth)
- **Reproductive**: bud, bloom, flower (sexual reproduction)
- **Maturation**: mature, ripen (fruit/seed development)
- **Reproduction**: breed, spawn, reproduce (offspring creation)

### Causal Chains
- Moisture + warmth → germinate → seedling emergence → growth
- Seedling + nutrients + sunlight → grow → plant expansion → biomass
- Maturity + seasonality → flower → reproduction → fruit development
- Sexual drive + conditions → breed → offspring → population growth

## 3. EMITTING VERBS (14 verbs)

**Definition**: Release of substances, energy, or materials from a source.

### Emission Type Spectrum

**Physiological Release**
- excrete, secrete, exhale, perspire, urinate

**Liquid Emission**
- leak, drip, ooze, seep, spray

**Forceful Discharge**
- discharge, expel, eject, spew

**Energy/Radiation**
- radiate, emit, beam, give off

### Emission Rate Gradient
- **Continuous slow**: ooze, seep, leak, drip
- **Moderate**: exhale, secrete, discharge, exude
- **Forceful/rapid**: expel, eject, spew, spray
- **Energetic**: radiate, emit, beam

### Fundamental Antonym
- emit ↔ absorb (release vs. intake)

## 6. YIELDING VERBS (9 verbs)

**Definition**: Production of results, resources, or supply outputs.

### Yield Type Categories

**Agricultural Yield**
- yield, bear, produce, generate

**Supply/Service Provision**
- provide, supply, furnish, deliver, render

**General Output**
- output, give

### Supply Chain Progression
- Agricultural production → yield → harvest → supply delivery
- Manufacturing → output → distribution → supply provision
- Service capability → deliver → customer satisfaction

### Fundamental Antonym
- provide ↔ deprive (giving vs. withholding)
- yield ↔ consume (production vs. consumption)
