## 1. GRASPING VERBS (16 verbs)

**Definition**: Control and holding of objects with hands/manipulators.

### Semantic Hierarchy

**Forceful Seizure** (aggressive grasping)
- seize, snatch, grab, catch

**Secure Holding** (stable, controlled)
- grasp, grip, hold, clasp

**Compressed/Firm Holding** (tension-based)
- clench, squeeze, pinch, clutch

**Specialized Grasping**
- embrace (affectionate), grapple (struggle-based)
- clamp (tool-based), clutches (metaphorical control)

### Interconnectivity Leaders
| Verb | Interconnections | Synonymic Density |
|------|------------------|-------------------|
| grip | 9 | highest variety of synonyms |
| grasp | 7 | versatile grasping action |
| seize | 6 | forceful capture |
| snatch | 6 | rapid seizure variant |

### Causal Patterns
- **Initiation**: prehension intent + object presence → grasp
- **Maintenance**: grasp → hold → possess → control
- **Intensification**: hold → grip → clench (force increase)
- **Release**: any grasping verb ↔ antonym (release, drop, let go)

### Key Antonym Pairs
- grasp ↔ release | grip ↔ loosen | hold ↔ drop | seize ↔ free

## 2. PUSHING/PULLING VERBS (14 verbs)

**Definition**: Linear force application causing object displacement.

### Bidirectional Opposition
**Push Verbs** (object away from source)
- push, shove, thrust, drive, press

**Pull Verbs** (object toward source)
- pull, drag, haul, draw, extract, tug, yank

**Specialized Actions**
- pry (leveraged extraction)
- wrench (twisting extraction)
- heave (heavy pulling with effort)

### Interconnectivity Leaders
| Verb | Interconnections | Role |
|------|------------------|------|
| pull | 10 | most central pulling verb |
| push | 3 | prototypical pushing action |
| drag | 4 | friction-based pulling |
| draw | 6 | abstract pulling (also sketching) |

### Force-Distance Spectrum
- **Maximum Force, Short Distance**: shove, thrust
- **Moderate Force, Medium Distance**: push, pull, drag
- **Sustained Force, Long Distance**: haul, tow, heave
- **Mechanical Advantage**: pry, wrench, extract (tool-assisted)

### Causal Chains
- Force application → push → object displacement → work done
- Resistance present → drag → friction opposition → slow motion
- Heavy load → haul → sustained effort → distance coverage
- Stuck object → pry/wrench → leverage application → extraction

### Speed/Force Gradient
**Gentle/Casual Throws**
- toss, lob (arc emphasis, soft landing)

**Standard Throws**
- throw, pitch, cast (moderate force, controllable)

**Forceful/Violent Throws**
- hurl, fling, sling (high velocity, emotional intensity)

**Specialized Throwing**
- chuck (informal), launch (mechanized), catapult (extreme force), propel (general acceleration)

### Interconnectivity Leaders
| Verb | Interconnections | Characteristics |
|------|------------------|-----------------|
| throw | 12 | prototypical; most synonymic variety |
| hurl | 7 | aggressive throwing variant |
| fling | 7 | wild, emotional throwing |
| cast | 7 | specialized (fishing, voting) |

### Trajectory-Speed Relationships
- **High Arc, Low Speed**: lob, toss (distance maximization)
- **Low Arc, High Speed**: pitch, sling (speed maximization)
- **Extreme Speed**: catapult, launch, propel (mechanical assistance)

### Causal Patterns

- Throwing force → throw → object flight → catch (antonym interaction)

- STRIKING verbs: impact tools, percussion mechanisms

**Kinematic Primitives**
- PUSHING/PULLING: linear actuators, cable-based systems
