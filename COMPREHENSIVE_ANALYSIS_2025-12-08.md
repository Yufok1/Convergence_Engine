## 🎯 PROJECT DESIGN & ARCHITECTURE

### Core Design: The Butterfly Metaphor

```
                    🦋 THE BUTTERFLY SYSTEM 🦋
                           
                    ┌─────────────────┐
                    │   EXPLORER      │
                    │  (Body/Breath)  │
                    │ Synchronization │
                    │  & Governance   │
                    └────────┬────────┘
                             │
                ┌────────────┴────────────┐
                │                         │
        ┌───────▼────────┐      ┌────────▼───────┐
        │ REALITY SIM    │      │  DJINN KERNEL  │
        │ (Left Wing)    │      │ (Right Wing)   │
        │                │      │                │
        │ • Evolution    │      │ • VP Monitor   │
        │ • Networks     │      │ • Traits       │
        │ • Neural Sys   │      │ • UUID Anchor  │
        │ • Language     │      │ • Math Gov     │
        └────────────────┘      └────────────────┘
```

**Design Philosophy:**
- **One Process, Three Systems**: Unified execution, not independent services
- **Breath-Driven**: Explorer's breath engine synchronizes all components
- **Event-Based Coordination**: Loose coupling via event bus
- **Graceful Degradation**: System works even if subsystems unavailable

**Responsibilities:**
- Breath engine: Primary synchronization clock

**Key Classes:**

- `SymbioticNetwork` - Network dynamics

**Features:**

- Dual inheritance: genetic + neural weights
- Alliance warfare system

#### 3. Djinn Kernel (Right Wing) - `kernel/`

- Current lazy-import strategy is adequate for now
