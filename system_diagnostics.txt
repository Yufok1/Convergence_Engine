16. Research Notepad System ⭐ NEW (Quick Win #7)

Status: SUCCESS / FAILED / PARTIAL
- Notepad panel visible in CRA chat interface
- CRA can add, read, search, and summarize notes
- Notes persist across sessions

Entry Types (Actions):
1. observe: Record observations
   - Fields: content (required), events (optional array of event IDs)
   - Example: {"action": "observe", "content": "VP spiked to 0.85 at 14:32:05", "events": ["evt_123"]}

2. hypothesize: Form hypotheses
   - Fields: content (required), confidence (low/medium/high), events (optional)
   - Example: {"action": "hypothesize", "content": "High VP triggers collapse", "confidence": "medium"}

3. causation: Document causal relationships
   - Fields: content (required), cause (event ID), effect (event ID)
   - Example: {"action": "causation", "content": "Config change caused modularity drop", "cause": "evt_config_123", "effect": "evt_collapse_456"}

4. analyze: Record pattern analysis
   - Fields: content (required), events (optional)
   - Example: {"action": "analyze", "content": "Pattern: VP spikes precede collapses by 10-15 cycles"}

5. conclude: Draw conclusions
   - Fields: content (required), events (optional)
   - Example: {"action": "conclude", "content": "Confirmed: reproduction_rate > 1.5 causes instability"}

6. question: Ask questions for later investigation
   - Fields: content (required)
   - Example: {"action": "question", "content": "Why does organism count spike before collapse?"}

7. todo: Add research tasks
   - Fields: content (required)
   - Example: {"action": "todo", "content": "Investigate neural sync correlation with VP"}

8. auto: Internal reasoning notes (not shown prominently)
   - Fields: content (required)
   - Example: {"action": "auto", "content": "Need to trace root causes of the 14:32 event"}

Reference Commands:
- read: Read all notes or filter by type
  - {"action": "read"} - all notes
  - {"action": "read", "type": "hypothesis"} - filter by type
- search: Search notes by query
  - {"action": "search", "query": "VP spike"}
- summary: Get summary of all notes
  - {"action": "summary"}

CRA Marker Format:
[[NOTEPAD: {"action": "observe", "content": "...", "events": [...]}]]
[[NOTEPAD: {"action": "hypothesize", "content": "...", "confidence": "high"}]]
[[NOTEPAD: {"action": "causation", "content": "...", "cause": "evt_1", "effect": "evt_2"}]]
[[NOTEPAD: {"action": "read", "type": "hypothesis"}]]
[[NOTEPAD: {"action": "search", "query": "collapse"}]]
[[NOTEPAD: {"action": "summary"}]]

Frontend Integration:
- processNotepadCommand() parses CRA responses for [[NOTEPAD: ...]] markers
- window.craNotepad object provides programmatic access
- notepadAddEntry() adds entries to the notepad panel
- Notepad panel shows entries with timestamps, types, and content

Best Practices for CRA:
- Use #hashtags in content for categorization (#vp_spike #collapse #neural)
- OBSERVE before analyzing - record what you see first
- HYPOTHESIZE with confidence levels - be honest about uncertainty
- DOCUMENT CAUSATION with event IDs - make chains traceable
- ANALYZE patterns across multiple observations
- CONCLUDE only when evidence is strong
- QUESTION things you don't understand - revisit later
