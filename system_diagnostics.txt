   - Example: {"action": "causation", "content": "Config change caused modularity drop", "cause": "evt_config_123", "effect": "evt_collapse_456"}

4. analyze: Record pattern analysis
   - Fields: content (required), events (optional)
   - Example: {"action": "analyze", "content": "Pattern: VP spikes precede collapses by 10-15 cycles"}

5. conclude: Draw conclusions
   - Fields: content (required), events (optional)
   - Example: {"action": "conclude", "content": "Confirmed: reproduction_rate > 1.5 causes instability"}

6. question: Ask questions for later investigation
   - Fields: content (required)
   - Example: {"action": "question", "content": "Why does organism count spike before collapse?"}

7. todo: Add research tasks
   - Fields: content (required)
   - Example: {"action": "todo", "content": "Investigate neural sync correlation with VP"}

8. auto: Internal reasoning notes (not shown prominently)
   - Fields: content (required)
   - Example: {"action": "auto", "content": "Need to trace root causes of the 14:32 event"}

Reference Commands:
- read: Read all notes or filter by type
  - {"action": "read"} - all notes
  - {"action": "read", "type": "hypothesis"} - filter by type
- search: Search notes by query
  - {"action": "search", "query": "VP spike"}
- summary: Get summary of all notes
  - {"action": "summary"}
